

# webTrials

Experiments and prototypes for working with **web pages, components, and front‑end technologies**. This repository serves as a sandbox for testing ideas in **HTML, CSS, TypeScript, and Angular**, with a focus on interactive UI elements and styling trials.

---

## 📂 Project Structure
- **`WebStuff/`** – Angular project containing component experiments (e.g., diamond component styling).
- **`introduction.html`** – Standalone HTML introduction page.

---

## 🛠️ Technologies Used
- **HTML** – Core markup for pages and prototypes  
- **TypeScript** – Angular components and logic  
- **CSS** – Styling and layout experiments  
- **Angular** – Framework for building interactive components  

---

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18+ recommended)  
- **Angular CLI** (`npm install -g @angular/cli`)  

### Installation
```bash
# Clone the repository
git clone https://github.com/nickleus-j/webTrials.git
cd webTrials/WebStuff

# Install dependencies
npm install
```

### Running the Project
```bash
# Start Angular dev server
ng serve

# Open in browser
http://localhost:4200
```
